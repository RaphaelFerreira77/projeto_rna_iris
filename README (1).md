# Rede Neural Artificial do zero - Classificação do Iris

Atividade da disciplina de Inteligência Artificial - UNIPAC Barbacena.

Rede neural 4-8-3 (ReLU + Softmax) implementada apenas com NumPy,
com Forward Pass, Cross-Entropy, Backpropagation e Gradiente Descendente
escritos manualmente. Scikit-Learn é usado somente para carregar e
dividir os dados.

## Como executar

```
pip install -r requirements.txt
python rna_iris.py
```
